# AI 协作记录

## 1. 协作目标与原始约束

初始需求来自 `docs/实现提示词.md` 与 `docs/实现要求.txt`。约束重点包括：离线单机运行、真实输血业务闭环、JWT 登录与 RBAC、业务数据可追溯、界面专业、Git 提交规范，以及课堂现场可演示。

AI 没有被要求一次性生成全部系统，而是按领域拆分：基础骨架、认证、血液入库、库存与效期、临床申请、配血、发血、执行、不良反应、追溯、报废、预警、报表、系统管理和前端视觉。每个模块完成后单独运行或检查，再按 Conventional Commits 提交。

## 2. 提示词组织方式

本项目采用“总目标 + 业务规则 + 页面约束 + 验收条件”的分层写法：

1. 总目标明确角色、业务闭环、技术栈与离线边界。
2. 业务规则写到可执行程度，例如 ABO/Rh 矩阵、Rh 阴性限制、四项发血核对、FEFO 推荐。
3. 页面约束明确医疗蓝主色、低饱和背景、组件图标、操作列单行和路由加载兜底。
4. 验收条件明确 pytest、HTTP E2E、403 越权、审计日志和 Git 提交格式。
5. 对 AI 的错误输出使用“现象 + 原因判断 + 约束”反馈，而不是只说“再好看一点”。例如白屏反馈会要求检查路由懒加载、Suspense、组件导入和错误兜底。

完整的初始提示词保留在 `docs/实现提示词.md`，本文只记录协作方法和人工介入，不重复整份提示词。

## 3. 人工介入点与修改原因

| 介入点 | AI 产物或问题 | 人工判断与修改 | 原因 |
| --- | --- | --- | --- |
| 页面加载白屏 | 部分路由切换期间出现整页白屏 | 改为路由懒加载、`Suspense`、`RouteLoading` 骨架与路由级错误兜底（`baa0597`） | 网络或组件加载异常时仍需保留可恢复界面，不能整页失去反馈 |
| 图标比例不一致 | 手写 SVG 图标在不同字号下变形 | 统一替换为 Element Plus 组件图标（`14b33d7`） | 组件图标有稳定视口和尺寸约束，表格与按钮中更一致 |
| 操作按钮换行 | 库存管理等表格操作列经常掉到第二行 | 抽出 `TableActions` 统一渲染，限制主操作数量并折叠次要操作（`cc97053`） | 操作列宽度稳定比单页分别调样式更可维护 |
| 背景过深 | 渐变和 SVG 纹理浓度偏高，偏离医疗业务气质 | 降低装饰透明度与背景饱和度（`ae915ad`） | 长时间录入场景需要低干扰，视觉层次不能让用户疲劳 |
| 按钮缺少反馈 | 关键操作与普通文字按钮区分不足 | 增加医疗蓝渐变、SVG 装饰与悬停动效（`bbfdbf2`、`b910bf1`） | 关键动作需要明确视觉优先级，同时保持业务系统克制感 |
| 页面版本小字 | 出现“版本”“演示版”等无关文字 | 从前端移除（`7b0fa5f`） | 验收展示应聚焦业务，不把开发自述放进产品界面 |
| README 对内痕迹过重 | 文档更像开发过程记录 | 重构为对外展示版（`03b117f`） | 项目说明应服务首次阅读者，过程材料单独进入 docs |
| 本地启停脚本 | `.bat` 被版本库跟踪 | 加入忽略并停止跟踪，README 改为手工启动 | 批处理依赖本机路径，不属于可移植源码 |
| 越权证据不足 | 原有测试未显式覆盖系统日志与用户管理 | 新增医生/护士访问系统管理接口的 403 测试 | 验收要求必须有自动化证据，不能只靠界面菜单隐藏 |
| 审计证据不足 | 发血日志已写入但测试未断言 | 在业务测试和 E2E 中按发血记录号反查日志 | 证明“刚操作的动作可审计”，避免只验证日志页面存在 |

## 4. AI 使用边界

- 本项目运行时不调用外部大模型，也不依赖网络 API。
- 配血推荐、临期提醒、低库存提醒、待配血超时提醒均是可解释的规则计算，属于离线智能辅助，不是伪造的“聊天 AI”。
- 所有业务状态由数据库和后端规则决定，前端不自行编造完成状态。
- 费用管理和外部 HIS/LIS 实时接口未实现，AI 生成内容也没有虚构这部分完成度。

## 5. 验证方式

本次验收补齐后的可重复证据：

```text
backend> python -m pytest -q
7 passed
```

```text
backend> python tests/e2e_api.py --base-url http://127.0.0.1:5000/api
ACCEPTANCE PASSED
```

E2E 同时打印申请单号、发血记录号、审计日志证据，并验证普通角色访问系统管理接口返回 403。

## 6. 答辩建议

- 先讲业务闭环，再讲技术实现，不要从页面组件开始罗列。
- 重点展示一次“不相容被拦截”，说明安全规则在后端而不是只在界面。
- 用现场生成的发血记录号去查审计日志，证明操作与日志是同一条真实数据。
- 主动说明自备血、费用和外部接口的边界，比声称全部完成更可信。
- 讲人工介入时重点说“为什么改”，例如白屏涉及故障恢复，操作列涉及长期维护成本。
